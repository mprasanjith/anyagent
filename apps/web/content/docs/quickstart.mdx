This page takes you from install to a working script: detect an installed coding agent, run a read-only prompt on it, then upgrade the same script to stream live progress.

## Prerequisites

You need:

- Node.js 18 or later, or Bun
- At least one [supported agent CLI](/docs/adapters) installed and signed in

## Install

Add the package with your package manager:

```npm
npm i anyagent
```

## Detect and run a prompt

Create a file named `run-agent.ts`:

```ts
import { create, detect } from "anyagent";

// scans the user's `PATH` and returns every supported agent it finds.
const installed = await detect();
if (installed.length === 0) {
  throw new Error("No supported coding agent found.");
}

// wraps the first result in a runnable handle.
const agent = create(installed[0]);

// sends the prompt with `read` permission, so the agent inspects files but changes nothing
const result = await agent.run(
  "List the top-level scripts in package.json and what each one does.",
  { permission: "read" }
);

console.log(result.text);
```

Run the script:

```bash tab="Node.js"
node run-agent.ts
```

```bash tab="Bun"
bun run-agent.ts
```

The agent’s answer prints to your terminal.
