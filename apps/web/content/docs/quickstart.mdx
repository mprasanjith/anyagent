This page takes you from install to a working script: detect a coding agent installed on your machine and run a read-only prompt on it.

## Prerequisites

You need:

- Node.js 22.18 or later, or Bun, to run the TypeScript example directly
- At least one [supported agent](/docs/adapters) installed and signed in

AnyAgent itself runs on Node.js 18 or later; the newer version only matters for running a `.ts` file without a build step.

## Install

Add the package with your package manager:

```npm
npm i anyagent
```

## Write the script

Create a file named `run-agent.ts`:

```ts
import { create, detect } from "anyagent";

const installed = await detect();
const [first] = installed;
if (!first) {
  throw new Error("No supported coding agent found.");
}

const agent = create(first);
if (!agent.supports("readOnly")) {
  throw new Error(`${first.name} cannot guarantee a read-only run.`);
}

const result = await agent.run(
  "List the scripts in package.json and what each one does.",
  { readOnly: true }
);

console.log(result.text);
```

`detect()` scans your `PATH` and returns every supported agent it finds, and `create()` wraps the first result in a runnable handle. `agent.supports("readOnly")` confirms this agent can guarantee a read-only run, and `readOnly: true` then confines it to reading, so the agent inspects files without changing anything.

## Run the script

Run it from a project directory, since the prompt asks about that project’s `package.json`:

```bash tab="Node.js"
node run-agent.ts
```

```bash tab="Bun"
bun run-agent.ts
```

When the run finishes, the agent’s answer prints, worded by whichever agent you have installed:

```txt
package.json defines three scripts:

- build: compiles src/ to dist/ with tsc
- test: runs the unit test suite
- lint: checks the source with eslint
```
