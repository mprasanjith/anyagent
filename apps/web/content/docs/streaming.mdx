title: Stream progress
description: Iterate a run to render the agent’s events live, and stop a run cleanly.
---

Every `agent.run()` returns a handle you can iterate as well as await, so showing progress needs no second method: loop over the run for live events, await it for the final result, or both on the same handle. A run can take minutes, and one that prints nothing looks hung, so anything interactive should show what the agent is doing.

Each example creates its agent from the `claude-code` adapter, so the blocks run as pasted on a machine with the Claude Code CLI installed and signed in. An `Agent` built from a detection result behaves the same; see [Run agents](/docs/run-agents).

## Loop over events

Iterating a run yields an `AgentEvent` each time the agent produces one. Loop over it to build a live display in a CLI:

```ts
import { create } from "anyagent";
import { claudeCode } from "anyagent/claude-code";

const agent = create(claudeCode());
const prompt = "Fix the failing test in test/parser.test.ts.";

for await (const event of agent.run(prompt)) {
  if (event.type === "text-delta") {
    process.stdout.write(event.text);
  } else if (event.type === "tool-call") {
    console.log(`\n[running ${event.name}]`);
  } else if (event.type === "done") {
    console.log("\nDone.");
  }
}
```

The answer prints as it streams, with a line for each tool the agent invokes:

```txt
I'll look at the failing test first.
[running read]
[running edit]
The test expected a trailing newline; parse() now preserves it.
Done.
```

Tool events carry the shared [`ToolName`](/docs/api#toolname) vocabulary on `name` (`read`, `edit`, `bash`, …) regardless of what the CLI calls the tool natively; the CLI’s own name is on `event.nativeName`. [`AgentEvent`](/docs/api#agentevent) lists the full event vocabulary and each event’s fields. How much text one `text-delta` carries varies by agent, from a token to a whole assistant message, but concatenating every delta’s `text` always reproduces `RunResult.text` exactly. `reasoning-delta` events carry the model’s visible thinking on CLIs that stream it; render or ignore them, they are never part of `RunResult.text`.

The `session` event arrives once, early, carrying the id the run can later be resumed under; persist it as it appears and a crash mid-run still leaves you able to continue the conversation.

## Get the final result

Await the same handle for the [`RunResult`](/docs/api#runresult), before, during, or after iterating — one run serves both consumers:

```ts
import { create } from "anyagent";
import { claudeCode } from "anyagent/claude-code";

const agent = create(claudeCode());
const run = agent.run("Summarize the open TODOs in this repo.");

for await (const event of run) {
  if (event.type === "text-delta") {
    process.stdout.write(event.text);
  }
}
const result = await run;
console.log(`\n${result.usage?.outputTokens ?? "?"} output tokens`);
```

The terminal `done` event carries the same result awaiting resolves with.

## Agents without a live stream

When an agent’s `capabilities.streaming` is `false`, the CLI prints a single final payload rather than a live stream. AnyAgent then delivers the whole answer as one `text-delta` followed by `done`. Your loop needs no special case: it renders one large delta instead of many small ones and works unchanged.

## Stop a run

Breaking out of an iteration loop stops watching, never the agent: the run continues to completion, and awaiting the handle still resolves. To stop the agent, call `run.abort()` or pass an `AbortSignal`; either terminates the underlying process and the run throws `AnyAgentError` with `code: "Aborted"`. Wire it to Ctrl+C so the end user can stop a run and exit cleanly:

```ts
import { create } from "anyagent";
import { AnyAgentError } from "anyagent/errors";
import { claudeCode } from "anyagent/claude-code";

const agent = create(claudeCode());
const run = agent.run("Migrate the config files in config/ to TypeScript.");
process.on("SIGINT", () => run.abort());

try {
  for await (const event of run) {
    if (event.type === "text-delta") {
      process.stdout.write(event.text);
    }
  }
} catch (err) {
  if (err instanceof AnyAgentError && err.code === "Aborted") {
    console.log("\nCancelled.");
    process.exit(0);
  }
  throw err;
}
```

There is no timeout option, so a run against a hung CLI waits indefinitely. Bound it with a signal: pass `signal: AbortSignal.timeout(300_000)` in the run’s options to end it after five minutes with an `Aborted` error.
