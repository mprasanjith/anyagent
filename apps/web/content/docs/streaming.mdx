This page shows how to render an agent’s activity live with `agent.runStream` and cancel a run with an `AbortSignal`. A run can take minutes, and one that prints nothing looks hung, so anything interactive should show what the agent is doing.

Each example creates its agent from the `claude-code` adapter, so the blocks run as pasted on a machine with the Claude Code CLI installed and signed in. An `Agent` built from a detection result behaves the same; see [Run agents](/docs/run-agents).

## Loop over events

`agent.runStream(prompt, opts)` is an async generator that yields an `AgentEvent` each time the agent produces one. Loop over it to build a live display in a CLI:

```ts
import { create } from "anyagent";
import { claudeCode } from "anyagent/claude-code";

const agent = create(claudeCode());
const prompt = "Fix the failing test in test/parser.test.ts.";

for await (const event of agent.runStream(prompt)) {
  if (event.type === "text-delta") {
    process.stdout.write(event.text);
  } else if (event.type === "tool-call") {
    console.log(`\n[running ${event.name}]`);
  } else if (event.type === "done") {
    console.log("\nDone.");
  }
}
```

The answer prints as it streams, with a line for each tool the agent invokes:

```txt
I'll look at the failing test first.
[running read]
[running edit]
The test expected a trailing newline; parse() now preserves it.
Done.
```

Tool events carry the shared [`ToolName`](/docs/api#toolname) vocabulary on `name` (`read`, `edit`, `bash`, …) regardless of what the CLI calls the tool natively; the CLI’s own name is on `event.nativeName`. The full event vocabulary is `session`, `text-delta`, `reasoning-delta`, `tool-call`, `tool-result`, `file-change`, `usage`, and `done`; [`AgentEvent`](/docs/api#agentevent) lists each one’s fields. How much text one `text-delta` carries depends on the agent, from a token to a whole assistant message, but concatenating every delta’s `text` always reproduces `RunResult.text` exactly. `reasoning-delta` events carry the model’s visible thinking on CLIs that stream it; render or ignore them, they are never part of `RunResult.text`.

The `session` event arrives once, early, carrying the id the run can later be resumed under; persist it as it appears and a crash mid-run still leaves you able to continue the conversation.

## Get the final result

The `done` event carries the final `RunResult` on `event.result`. It is the same object `agent.run` resolves with: `text`, `events`, `usage`, `sessionId`, and `raw`. If you drive the generator by hand instead of looping, `runStream`’s return value is that same result:

```ts
import { create } from "anyagent";
import { claudeCode } from "anyagent/claude-code";

const agent = create(claudeCode());
const stream = agent.runStream("Summarize the open TODOs in this repo.");

let next = await stream.next();
while (!next.done) {
  // render next.value, an AgentEvent
  next = await stream.next();
}
console.log(next.value.text); // next.value is the RunResult
```

## Agents without a live stream

When an agent’s `capabilities.streaming` is `false`, the CLI prints a single final payload rather than a live stream. AnyAgent then delivers the whole answer as one `text-delta` followed by `done`. Your loop needs no special case: it renders one large delta instead of many small ones and works unchanged.

## Cancel a run

Pass an `AbortSignal` to cancel a run. Aborting terminates the underlying process, and the run throws `AnyAgentError` with `code: "Aborted"`. Wire it to Ctrl+C so the end user can stop a run and exit cleanly:

```ts
import { create } from "anyagent";
import { AnyAgentError } from "anyagent/errors";
import { claudeCode } from "anyagent/claude-code";

const agent = create(claudeCode());
const prompt = "Migrate the config files in config/ to TypeScript.";

const controller = new AbortController();
process.on("SIGINT", () => controller.abort());

try {
  for await (const event of agent.runStream(prompt, {
    signal: controller.signal,
  })) {
    if (event.type === "text-delta") {
      process.stdout.write(event.text);
    }
  }
} catch (err) {
  if (err instanceof AnyAgentError && err.code === "Aborted") {
    console.log("\nCancelled.");
    process.exit(0);
  }
  throw err;
}
```

Breaking out of the loop early also stops the run: AnyAgent kills the underlying process for you, so early exit is safe without an explicit abort.

There is no timeout option, so a run against a hung CLI waits indefinitely. Bound it with the same mechanism: pass `signal: AbortSignal.timeout(300_000)` to end the run after five minutes with an `Aborted` error.
