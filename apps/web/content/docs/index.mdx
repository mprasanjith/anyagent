AnyAgent is a TypeScript library that detects which of the [supported coding-agent CLIs](/docs/adapters) a machine already has installed and drives them through one interface.

It’s an ESM module with zero runtime dependencies and runs on Node.js 18+ and Bun.

## Why it exists

The developers who use your tool likely already have a coding agent. With AnyAgent you can write prompts and skills that run on their agent, under their login, on their subscription. You don’t need to set up API keys or pay inference bills.

## Who this is for

AnyAgent suits tools that run a defined task against the user’s own project.

For example:

- **Setup wizards**: an `init` command that wires your SDK into the user’s codebase
- **Migration and codemod runners**: apply a framework upgrade across a repo
- **Generators**: produce changelogs, tests, or docs from the current source
