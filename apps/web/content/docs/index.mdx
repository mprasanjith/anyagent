AnyAgent is a TypeScript library that detects which of the [supported coding-agent CLIs](/docs/adapters) a machine already has installed and drives them through one interface. It has zero runtime dependencies, ships as ESM, and runs on Node 18+ or Bun. You write one prompt-and-run flow, and it works against whichever supported agent your end user has signed in to.

## Why it exists

The developers who use your tool already have a coding agent installed and signed in. AnyAgent puts that install to work: the prompt you write runs on their agent, under their login, on their subscription. You collect no API keys and pay no inference bill. Your tool ships the logic; the user's agent supplies the model and the auth.

## A first look

Three calls take you from detection to an answer:

```ts
import { create, detect } from "anyagent";

const [found] = await detect();
if (!found) throw new Error("No supported coding agent installed.");

const agent = create(found);
const result = await agent.run("Summarize this project in one sentence.", {
  permission: "read",
});
console.log(result.text);
```

`detect()` returns every supported agent on the user's `PATH`, `create()` wraps one in a runnable handle, and `run()` sends a prompt and resolves with the answer on `result.text`. The [Quickstart](/docs/quickstart) walks through this end to end.

## What you build with it

AnyAgent suits tools that run a defined task against the user's own project:

- **Setup wizards**: an `acme init` command that wires your SDK into the user's codebase
- **Migration and codemod runners**: apply a framework upgrade across a repo
- **Generators**: produce changelogs, tests, or docs from the current source
