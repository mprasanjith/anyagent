These are the agent CLIs AnyAgent supports. `detect()` scans for all of them, and each has its own subpath export for targeting it directly. Everything CLI-specific lives on the adapter’s page: how detection finds the CLI, the capability table it declares, the native flag behind each run option, what its stream produces, and where its session id lives on `raw`.

    </Card>
  ))}
</Cards>

The adapter pages share one section order, so a fact about one agent sits in the same place on every other. An adapter ships only against a verified audit and recorded real CLI output, never a guessed schema.
