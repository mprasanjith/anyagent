These are the agent CLIs AnyAgent supports. `detect()` scans for all of them, and each has its own subpath export for targeting it directly. Everything harness-specific lives on the agent’s adapter page: how detection finds it, the capability table it declares, how each run option maps to a native flag, what its stream produces, and where its session id lives on `raw`.

</Cards>

An adapter ships only against a verified audit and recorded real CLI output, never a guessed schema. To bring another CLI into this list, see [Adding an adapter](/docs/adding-an-adapter).
